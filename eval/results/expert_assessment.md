***REMOVED******REMOVED*** 3.【优先改进项 Top 5】（按影响面排序）

1. **接入 Reranker（影响面：所有查询的头部精度）**——混合检索 top20 → bge-reranker-v2-m3（本地）或 API 重排 → top5。预期 R@1 从 80.8% 提升到 90%+，同时削减 top5 噪声块、缓解表格类短板。实现点：`retriever.retrieve()` 尾部加重排钩子 + `RERANK_MODEL` 配置，用 `tune_retrieval.py` 做开关对比。
2. **把多跳/同义改写/对抗题纳入常驻评测集**——本次 3 条多跳虽全过，但样本太小且未进回归。建议新增 30 条多跳（跨文档双金标）、20 组同义改写对、20 条对抗错误前提，合入 `questions_v2.jsonl` 并在 `run_eval.py` 增加题型分项，防止后续改动回归。
3. **监控告警与 Token 计量**——`chat()` 已埋 `_last_usage`，端点不回传时用 tiktoken 按 prompt 字符数兜底估算；落 SQLite/CSV 指标（延迟、错误率、tokens/日），超阈值告警（哪怕先接企业微信 webhook）；补 P99 追踪。
4. **表格与多跳生成增强**——表格问答准确率 62.5% 是明确短板：对表格块使用专用提示词（保留行列结构+引导跨行对比），检索侧对表格块放宽 k；多跳场景在 prompt 中显式要求"分别引用多个来源"。
5. **安全二期：语义注入防御与权限**——正则之外增加轻量分类器（或 LLM 判别）拦截语义变体注入；建 20 条红队集进回归；若面向真实企业，需加知识库文档级 ACL（入库时打权限标签、检索时按用户过滤——Chroma `where` 原生支持）。
